# Basic REST API

## Description
A Basic REST API built using Node.js and Express.js. This project follows a simplified MVC architecture to manage student data through different HTTP methods.

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Features
- GET – Retrieve student data.
- POST – Add new student data.
- PUT – Update existing student data.
- PATCH – Update specific student information.
- DELETE – Remove student data.

## Project Structure
- **Models:** Manages student data.
- **Controllers:** Handles application logic and processes requests.
- **Routes:** Defines API routes and connects them to controllers.

## Installation & Setup
1. Run `npm install`.
2. Start the server using `node app.js`.
3. Server runs on `http://localhost:3000`.
